# v0.4.0

Tagged 2026-11-21. Previous release: `v0.3.0`.

The first public build. It is the first release cut from the public repository, and the first one signed with the release key.

MINOR by decision, not by the usual rule: no model, prompt, router, tool or sampling setting changed since `v0.3.0`.

## What changed

- The classic app's clear key shows only a trash icon. It deletes the conversation, and it used to read "New". Screen readers hear "Clear conversation".
- The model download screen says Gemma 4 is licensed under Apache 2.0 and that Offwire is not affiliated with Google. It replaces the Gemma Terms notice.
- The Settings back control is the same back arrow as on the Notes screen.
- A privacy policy is added under `docs/site/privacy/` and named in the Play listing.
- The classic app's release build is signed with a key kept outside the repository (`docs/RELEASING.md`, "Release signing").
- `versionCode` is `400`. Earlier releases all used `1`.
- The classic release APK carries only the arm64 native libraries. It is 365 MB, down from 533 MB with all four processor types.

## AI architecture at this tag

Unchanged from `v0.3.0`. Models, router model and head, prompts, tools and generation settings are as described in `docs/releases/v0.3.0.md`, `docs/releases/v0.2.0.md` and `docs/releases/v0.1.0.md`.

## Evals

Not rerun. The paths the release evals measure are identical to `v0.3.0`: the router, the prompts in `SystemInstruction.kt`, the engine code, the bundled model assets, the library versions and the eval fixtures. The `v0.3.0` table and its result files in `eval/releases/v0.3.0/` stand for this release.

## Known gaps

The same as `v0.3.0`: G1, G2 and G5 to G11.

- G12: The release build prints Kotlin metadata version messages from a dependency check and still succeeds. The debug build does not print them.
- G13: The release APK is arm64 only, so it does not install on an x86 emulator. Debug builds still carry every processor type.
- G14: Only the classic app has a signed release build. The console app and the iOS app are not part of this release.

## Acceptance

Not run on a phone for this release. The gates passed on the release commit: quality, iOS, and device on `emulator-5554`. The signed arm64 release APK was installed and opened on `emulator-5554`, which is arm64. It has not been installed on a phone.
