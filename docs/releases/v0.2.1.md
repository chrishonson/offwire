# v0.2.1

Tagged 2026-11-14. Previous release: `v0.2.0`. The AI code is commit `811a61f`. The tag adds the version number and these notes.

## What changed

- Asked what they saved about something no note mentions, Gemma says there is no note about it instead of reading back an unrelated note. R2 answering from a saved note on E2B went from 7 to 12 of 12.
- Asked what it can do, Gemma says it can talk, answer questions and save notes. O2 capability questions on E2B went from 24 to 27 of 27. The cloud loop measured 70 of 70 on the capability rows over 10 runs each.
- `SystemInstructionTest` matches the new chat-turn line.
- The eval scripts can run Gemma behind an OpenAI-compatible endpoint from a cloud session (`scripts/eval/hosted.py`, `scripts/eval/cloud/`). The app does not use this.

## AI architecture at this tag

Unchanged from `v0.2.0` except for two prompt sentences in `core/src/commonMain/kotlin/com/chrishonson/gemmavoice/llm/SystemInstruction.kt`. Turn flow, models, router, tools and generation settings are as described in `docs/releases/v0.2.0.md` and `docs/releases/v0.1.0.md`.

| Turn | Added sentence |
|---|---|
| Android, any route other than SAVE | "When asked what you can do, say you can talk, answer questions and save notes." It comes before "When asked whether you can save notes, say yes." |
| Android, every route | In the notes paragraph: "When the user asks what they saved about something no note mentions, say they have no note about it." |
