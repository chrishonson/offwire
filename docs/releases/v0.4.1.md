# v0.4.1

Tagged 2026-11-25 on commit `ed748b6`. Previous release: `v0.4.0`.

The first build sent to the Google Play closed test. The app behaves the same as `v0.4.0`. PATCH: only the packaging and the version number changed.

## What changed

- The classic app builds as an app bundle for Google Play (`docs/RELEASING.md`, "Google Play bundle"). In the bundle, the Parakeet speech-to-text model and the MiniLM router model ship in the install-time asset pack `:model-pack`. That takes the base module from 237 MB to 49.7 MB, under Play's 200 MB limit. The pack is 187.7 MB.
- The app opens both models through `AssetManager` at the same paths as before, so no app code changed. The APK still carries them in its own assets.
- `versionCode` is `401`, so this version installs over `v0.4.0`.
- `PackagedModelsTest` is new. It loads the router model and the speech-to-text model from the installed app.
