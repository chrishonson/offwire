# v0.3.0

Tagged 2026-11-19. Previous release: `v0.2.1`. The AI code is commit `aac021f`. The tag adds the version number and these notes.

MINOR, because the router and the prompts changed.

## What changed

- The router drops spoken lead-ins ("uh", "um", "alright", "buddy" and others) before routing, and splits a turn on "and" before a request verb. R1 went from 266 to 270 of 304.
- Chat turns keep brainstorm replies to two or three ideas and at most one question, and build on the idea the user points back to ("the second one").
- Recap turns include the saved note when there is one.
- The intro drops "friendly".
- E4B only: no praise or "does that sound good?" endings, one or two sentences when asked for shorter, counting back through topics on "the one before", and naming names, dates and numbers only when sure. The prompt comments in `SystemInstruction.kt` give the eval numbers for each line, and why E2B goes without them.
- E2B only: when told it is wrong, it keeps an answer it knows instead of agreeing.
- The app is named Offwire, with app ids under `app.offwire`.
- iOS reply speech plays through the mic's voice-processing engine, so the app no longer hears its own replies.
- The classic app is restyled as 90s hardware in light and dark. Settings is a gear icon, and the Notes key is labeled.

## AI architecture at this tag

Unchanged from `v0.2.1` except for the router's text cleanup and the prompt sentences above. Models, router model and head, tools and generation settings are as described in `docs/releases/v0.2.0.md` and `docs/releases/v0.1.0.md`.

| Part | Change |
|---|---|
| Router, `router/IntentRouter.kt` | `PREFIX` also strips spoken lead-ins. `SEGMENT` also splits on "and" before a request verb. Both mirror `router.py` and `embed_router.py`. |
| Prompt, `llm/SystemInstruction.kt` | Brainstorm and point-back sentence on chat turns, `RECAP_NOTES` when there are notes. E4B adds `NO_FLATTERY`, `SHORTER_ON_ASK`, `REACH_BACK` and `HONEST`. E2B adds `PUSHBACK`. The model file name picks the set (`shorterOnAskFor`). |

The longer prompt raised the Mac chat-turn prompt from 305 to 499 tokens on E4B and to 398 on E2B. That is most of the time-to-first-token rise below.

What the numbers say:

- The E2B drop on answering from a saved note is a scorer false positive. All 3 runs of `recall-meetup` answer "The AI meetup has been moved to the twenty-fourth.", which is right, but the scorer looks for "24".
- The E4B R2 misses are the rows that failed at v0.2.1, one more run each. `multi-save-and-timer` fails all 3 runs on the same unquoted `save_note` argument parse error (2 of 3 at v0.2.1). `act-cal-today` and `act-cal-tomorrow` each miss once by saying the calendar is empty. Both are do_action turns, which the app does not send.
- R4 E2B now passes `overheard-ask-next-turn`, the row it missed at v0.2.0 and v0.2.1.
- Time to first token rose with the prompt length: E4B chat turns 2.33 to 3.72 s on the Mac.

O2 save-decision was not run for this release.
